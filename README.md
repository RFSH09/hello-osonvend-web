# Hello by Osonvend - Website BETA

Website + customer web app for **Hello**, an AI smart vending fridge by OOO "OSONVEND", Tashkent.
Tagline: **Scan. Take. Go.**

## Status
Scaffolding. Planned stack: Next.js (App Router) + TypeScript + Tailwind + shadcn/ui + Framer Motion + next-intl (uz, uz-Cyrl, ru, en). Frontend runs on a mock API behind `/lib/api/*` until the Django endpoints are confirmed.

Full build spec: [docs/BUILD_SPEC.md](docs/BUILD_SPEC.md)
